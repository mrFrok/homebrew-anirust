# AniRust on Homebrew

On Apple silicon with macOS 15 or later, install the release app.

```sh
brew install --cask mrfrok/anirust/anirust
```

On Linux, build the desktop app and CLI from the same release source.

```sh
brew install --formula mrfrok/anirust/anirust
```

New stable versions are published here by the AniRust release workflow.
[AniRust source and other downloads](https://github.com/mrFrok/AniRust)
